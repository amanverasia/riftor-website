# Riftor website

The Astro site for [riftor.dev](https://riftor.dev). It introduces the
standalone, Pi-powered cybersecurity assessment harness and tracks the current
rebuild status.

## Development

Requires Node.js 22 or newer.

```sh
npm install
npm run dev
```

Build the static site with `npm run build`; preview the generated site with
`npm run preview`.
